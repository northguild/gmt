## Changeset

`.changeset/<name>.md`, `@northguild/gmt`: **minor** (house policy: no 2.0.0; breaking changes ship
in the current line). Plain text, written with `/changelog` once the diff is final:

- GMT now runs on `temporal-polyfill` 1.0.8 instead of `@js-temporal/polyfill` 0.5.1. Every function
  returns the same values.
- Bundle sizes: the floor and each measured entry, before → after, from `bundle-size.mjs --compare`.
- **Types:** the `Temporal` and `Intl` re-exports now carry `temporal-spec`'s types. List the public
  types whose `.d.ts` changed (slice 2 hands over the list). A consumer that used the old helper
  names through `Temporal.*` (e.g. `Temporal.RoundingMode`) must use its own alias.
- Objects from the two polyfills are not interchangeable; a project that also imports
  `@js-temporal/polyfill` directly should take `Temporal` from `@northguild/gmt`.
- A month amount past Temporal's range now returns the sentinel without running the polyfill's
  month arithmetic (same value as before).

No changeset for `gmt-oxlint`, `gmt-eslint`, `gmt-biome` (index § Corrections 1). `apps/dox` follows
the repo's Dox changeset practice.
