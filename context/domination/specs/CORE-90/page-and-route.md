## `apps/dox/src/components/SunshineProtectionAct.astro` (new)

The component renders the template on the server, then mounts it in a `<script>`, the way Morocco
does:

- `renderSunshineProtectionActTemplate()` writes every part before the script runs: the view switch, both
  maps' frames, both lists with every row, both pin panels, the legends, the national panel and
  the guidance cards. The page never grows once data arrives.
- `seedFromLocation("sunshineact")` reads `{ view: { kind, zone? | state? } }` and passes it to
  `mountSunshineProtectionAct(el, signal, seed)`. Catch with `showUnavailable`.

## `apps/dox/src/lib/sunshine-protection-act-mount.ts` (new)

```ts
export function renderSunshineProtectionActTemplate(): SafeHtml;
export async function mountSunshineProtectionAct(
  el: HTMLElement, signal: AbortSignal, seed?: SunshineActSeed, deps?: Partial<SunshineActDeps>,
): Promise<SunshineActHandle>;  // { setView(kind), pin(id | null), destroy() }
export type SunshineActSeed =
  | { kind: "today"; zone?: string }
  | { kind: "proposals"; state?: string };
```

Layout, top to bottom:

1. **The view switch.** `viewSwitch` (slice 1), legend "Show", with options "Today" and
   "Proposals". Today is checked by default, and the seed can change that. Changing the view
   swaps which map and list are shown (`hidden`), keeps each view's own pin, and moves no focus.
2. **Today map.** `wireFeatureMap` with these settings:
   - `featureKey: "tzid"`
   - `boundariesUrl: withBase("/timezone-boundaries-us.json")`
   - `projection: geoUsComposite` fitted
   - the ids from `us-region-zones.json`
   - `classOf` from the Worker row (slice 3); before the answer arrives, `"no-data"`
   - `onPin` fills the Today pin fields
   - `labelled` lists seven anchors: New_York, Chicago, Denver, Phoenix, Los_Angeles, Anchorage
     and Honolulu
3. **Proposals map.** `wireFeatureMap` with these settings:
   - `featureKey: "postal"`
   - `boundariesUrl: withBase("/state-boundaries-us.json")`
   - `overlayUrl: withBase("/timezone-boundaries-us.json")` for the zone lines, `aria-hidden`
   - `classOf` from `STATES` (slice 4), with unlisted states as `"none"`
   - `labelled: []`, so labels show on hover, focus and pin
   - fetched **only when the view is first shown**, under the same signal
4. **Pin panels**, one per view. They reserve their size the way the checkers' pin panel does.
   - Today fields: as in [today-endpoint.md](today-endpoint.md).
   - Proposals fields:
     - State: the NE `name`;
     - Position: the class words;
     - Since: "Law, 2019", or "Resolution, 2026"; territory rows show "—";
     - Condition: the row's `condition`, or "None stated";
     - As of: "13 November 2026", plus the runtime `ageWords`.
     - Arizona's pin adds: "The Navajo Nation keeps daylight time."
5. **Legend** under each map. Each class gets a swatch with a pattern and a word, and a count.
   The counts come from the data: Today counts rows by class, Proposals counts `STATES` by class.
6. **The national proposal** panel (Proposals view only). It holds the text from
   [guidance-text.md](guidance-text.md) and uses an `infoCard` (full border, bevel).
7. **"If the clocks stop changing"**: `keyPoints(…, US_GUIDANCE, heading)`. It is shown in both
   views.
8. **Captions** under the map:
   - "Insets are not to scale. Midway and Wake are listed but not drawn, and neither are the Northern Mariana Islands north of Saipan."
   - The data credits button: `TZ_BOUNDARIES`, `COASTLINES` and `STATE_BOUNDARIES`.

## Classes, patterns, colour

| View | Class | Word | Mark |
| ---- | ----- | ---- | ---- |
| Today | `changes` | Changes its clocks twice a year | solid fill |
| Today | `standard-all-year` | Same time all year | dots |
| Today | `no-data` | No data | outline only |
| Proposals | `standard-all-year` | Already on standard time all year | dots (same as Today) |
| Proposals | `daylight-if-allowed` | Daylight time all year if federal law changes | diagonal hatch |
| Proposals | `daylight-if-allowed` with `condition` | … only if a condition is met | cross-hatch |
| Proposals | `standard-proposed` | Standard time all year proposed | horizontal lines |
| Proposals | `none` | No adopted position | outline only |
| Proposals | Arizona | as `standard-all-year`, with a hatched Navajo Nation | hatched part from the zone overlay's `America/Denver` shape clipped to AZ |

- Colour goes on marks only, from the family's palette tokens, with light and dark values on
  `:root`. Text is never coloured.
- Patterns are SVG `<pattern>` defs that survive forced colours.
- **Do not reuse the checkers' "stopped" colour.** That colour means "a dated change happened".

## Readouts hold still

- The pin panels' values have reserved widths, `font-variant-numeric: tabular-nums` and
  `white-space: nowrap` (wrapping only in the Condition field, which has a reserved height of
  three lines).
- Paired readouts sit at opposite edges (`justify-content: space-between`).
- Pinning, switching views or a Worker answer arriving moves no card. Slice 8 tests this with a
  bounding box.

## Widths

- **1440.** The pin panel sits beside the map from 62rem of checker. The map's column is as wide
  as a frame filling the viewport's height allows, and the panel takes the rest (at least 20rem).
- **1024.** The checker is under 62rem, so the pin panel sits below the map.
- **No list where the map is drawn.** From 520px the drawn shapes are the keyboard path
  (`keyboard: "shapes"`), so the place list is shown only below 520px, or when the boundary file
  failed (`data-map="failed"`).
- **375 px.** The list is the map. Nothing is drawn and no boundary file is fetched. The view
  switch and the pin panel fit with the 16 px gutter and do not scroll sideways.
- **Keyboard only.** Tab reaches the switch (arrows change the view), then the map once (arrows,
  Home, End, Enter; the list below 520px), then the guidance links.

## Lifetimes

`mountSunshineProtectionAct` owns one `AbortController`, a child of `signal`. The Worker fetch, both
boundary fetches, both `wireFeatureMap` handles, the switch listener and any `ResizeObserver` all
end when it aborts. `destroy()` aborts it.

The page starts no timers. The Today map shows the instant the Worker answered, and "Next change"
is worded from it. No live clock is needed in phase 1.

## Time

- No `Date.now`, `new Date()` or `performance.now`.
- `ageWords` gets `today` from `getToday()` (`@northguild/gmt/plain/get`). Load it with a dynamic
  `import()` after the template mounts, so the polyfill stays off first paint.
- Every other time on screen comes from the Worker.
