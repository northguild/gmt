# Slice 8 · The block catalogue

Each shared block the next deck builds from, where it lives and what a deck gets from it. The
slice itself, the audit and its fixes are [Slice 8 · Reusable blocks](./s8-reusable-blocks.md).


| Block                     | Home                                                                        | What a deck gets                                                                                                                                                             |
| ------------------------- | --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Deck page                 | `src/pages/slides/[slug]/index.astro`, `presenter.astro`                    | One route for every deck: both pages take `deckRoutes()` from `src/slides/deck-pages.ts`; title, description, head entries and page tools from the `DeckEntry`               |
| Deck, Slide, Build, Notes | `src/components/slides/`                                                    | The stage, pinned places, builds and speaker notes; per-slide layouts by `layout`, never by `:has()` on a child                                                              |
| Visual, Swap, GmtStep     | `src/components/slides/`                                                    | The bug-slide pattern: a visual with its filing receipts, swapped for the GMT step on the next build                                                                         |
| CodeRun, GmtRun, RunLines | `src/components/slides/`                                                    | One run panel for every snippet on stage, laid out like a test runner: runtime heading, a shell command typed or a JS call in `DeckCode`, then one row with the Result and, beside a wrong one, the Expected value; `GmtRun` fills it from gmt calls run at build time (`gmtSteps`), opens with their imports (`importText`), labels results GMT and prints each filed bug's value beside them; a `FlapBoard` sits inside one |
| RunLabel                  | `src/components/slides/`                                                    | The label on every result: "✗ Result" red, "✓ Expected" green, "✓ Result" green, "∅ Result" amber (sentinel), the word replaceable by who gave it ("✓ GMT", "✗ Polyfill"); runs, flap rows and calendar figures use it, with the deck's `--gmt-deck-wrong` / `--gmt-deck-right` pair                                               |
| DeckTable                 | `src/components/slides/`                                                    | One table; `BundleSize.astro` shares it                                                                                   |
| DeckLive                  | `src/components/slides/`                                                    | One live panel (answer, questions, page tool) taking its data as props; presenter flag from the deck                                                                         |
| Deck runtime              | `src/slides/deck-runtime.ts` + `src/slides/<slug>/runtime.ts`               | The deck's stage data (places, lapses, pins, readiness rows) and live data (questions, recordings, tool question), loaded by slug                                            |
| `play` / `Frames`         | `src/lib/slides/frames.ts`                                                  | The one animation loop: typing, counters, lapses, the Sun glide, the filings count                                                                                           |
| Reduced motion            | `src/lib/reduced-motion.ts`                                                 | `prefersReducedMotion`                                                                                                                                                       |
| Visual registry           | `src/lib/slides/bug-visuals.ts`                                             | One `{ reset, play }` entry per `data-visual` kind: `run` (typed code, lines shown after it, rolls landing in turn), `pages`, `rows`                                          |
| Stage features            | `src/lib/slides/stage*.ts`                                                  | The camera core (`stage.ts`) plus opt-in `stage-reveal`, `stage-lapse` and `stage-filings`; `stage-keys` for the fly keys, `stage-deferred` for what loads after first paint |
| Stage data checks         | `src/lib/slides/stage-data.ts`, `deckStage` in `src/slides/deck-runtime.ts` | `checkStageNames`: a place, reveal zone or lapse a slide names that its own deck lacks fails the build                                                                       |
| gmt loading, DST jumps    | `src/lib/slides/gmt-loader.ts`, `transition-ms.ts`                          | One lazy gmt import after first paint; one "first offset change in these years"                                                                                              |
| Built-deck reader         | `scripts/built-deck.ts`                                                     | `builtSlides(dist, slug)` for a deck's own `built.test.ts`; `slides-built.test.ts` runs the shared rules over every deck                                                     |
| Zone-matrix runner        | `scripts/zone-matrix/node-runner.mjs`, `record-shape.mjs`                   | One way to run a Node version; one compact record shape and its reader                                                                                                       |
| Deck sheet                | `src/components/slides/slides.css`                                          | Stage, slide, layouts, builds, bar, pager, menu, dialogs, print; text-size tokens                                                                                            |
| Deck panel                | `src/components/slides/deck-panel.css`                                      | The one panel surface (`gmt-deck-panel`): the deck, the presenter's sections and the deck index cards                                                                        |
| Gate command line         | `scripts/lib/gate-cli.mjs`                                                  | Options, `--browsers`, the static server, and `gatePages` (built-site check, page contract, `--shard`) for every browser gate                                                |
| Widget rail state         | `src/components/ask/use-rail-widget.ts`                                     | The one open widget and its dispatch, for `/dox` and the deck's Dox slides                                                                                                   |
| Deck and presenter parts  | `src/lib/slides/deck-parts.ts`, `deck-dialogs.ts`, `deck-moves.ts`          | The slides read from the page, the dialog wiring and one action table, shared by the deck window and the presenter                                                           |
| Stage test harness        | `src/test/stage-fixture.ts`, `deck-stage-fixture.ts`                        | `stageHarness`, the engine, wall, loader, clock, theme and sky mocks, and one fixture deck for every stage test                                                              |
| Sky test host             | `src/test/sky-host.ts`                                                      | The sky's host with its two canvases                                                                                                                                         |
| ui-standards              | `.agents/skills/ui-standards/`                                              | The check for rules 2 to 8 on the lines a branch adds; `validate` and CI run it on every `apps/dox` change                                                                   |
| QR code, credits          | `src/components/slides/`                                                    | As built                                                                                                                                                                     |
