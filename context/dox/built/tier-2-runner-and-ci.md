# Tier 2: the gate runner and CI

Part of [built/index.md](index.md). The gates themselves: [tier-2-gates.md](tier-2-gates.md). Operator steps: [tier-6-runbooks.md](tier-6-runbooks.md).

## The runner

- `pnpm --filter dox gates` (`scripts/gates.mjs`) runs every gate from one build and one static server and prints one screen. Gates are data in `scripts/gates/registry.mjs` (`id`, `script`, `tier`, `browsers`, `fullBrowsers`, `themes`, `needs`, plus `args`, `base`, `browserArg`, `pages`). `select.mjs` turns changed files and the import graph (`graph.mjs`) into pages; `screen.mjs` prints.
- Tiers nest. `pr`: contrast-measure, grow-measure, readout-still, data-credits-check, esc-cascade, hero-phone, sound-check, rail-stored-still, canada-layout-check, rendered-links, frame-check, a11y-axe, a11y-tab-walk, a11y-media. `weekly` adds canada-clock-still, canada-stored-still, table-fit, plate-fit. `local` adds globe-smoke, html-diff, visual-diff (they need a GPU or a baseline).
- Page contract: every gate script answers `--list-pages` (a JSON array of site paths without `/gmt`, no browser, printed whole however long, since the runner reads it through a pipe), takes `--pages <path,...>` (an unknown path exits 2) and, when it loads pages, `--base <url>`. With `GATE_REPORT` set, each failure goes through `recordFinding` as `{ gate, rule, page, selector, browser, width, theme, message }` (`rule` is a short stable id such as `readout-moved`, never prose), and the run ends with `recordMeasured(gate, n)` (`scripts/gates/findings.mjs`, `contract.mjs`). Exit 0 without that line, or with `n = 0`, is `FAIL measured nothing`; exit 0 with findings is FAIL.
- `hero-phone` (`hero-phone-check.mjs`, Chromium and WebKit; pages `/` and `/guides/`; zone pinned to Africa/Nairobi) holds the stacked landing on six phone sizes (`hero-phone-check.mjs` lists them), in `?globe=canvas2d`: title, buttons, then the Earth on the first screen; the atmosphere whole; no carousel, hidden or scrolling pane; headings clear of the header; a tap on "Find a zone" that does not scroll and keeps the field in view; 44 px targets, failing on fewer than expected (sheet buttons, field, three options; four zoom buttons); a tap on the Earth that leaves the sheet shut; the zone card, dragged toward each edge, inside the stage and above the open sheet; a still disc under a drag; no sideways scroll; zero layout shift (engines that report it); stars smaller than at 1440 x 900; and the header rule (title not clipped, wordmark and name ≥ 12px, no Dox, GitHub or Discord link below 50rem, the hero row only "Get started" and "Ask Dox", no eyebrow, the h1 kept). At 1440 x 900 the carousel is wired; a stacked-to-locked resize shows only the pane the reader had scrolled to, with no entrance motion. CI runs the Chromium leg (`other`); WebKit runs locally with `--browsers webkit`.
- Page costs: a gate whose pages differ a lot in run time is `costs: true` in the registry and also answers `--list-page-costs` (each path's minutes). `readout-still` is the one: its costs are the `minutes` on each `TOOLS` entry, one WebKit run of that tool on one machine, since only the ratios matter. A page with no cost stops a sharded run.
- `grow-measure`, `readout-still`, `data-credits-check` and the three Canada scripts accept `firefox` in `--browsers`.
- The deadline (`--deadline <minutes>`) is enforced by `scripts/gates/run-command.mjs` (`runCommand`, tested in `run-command.test.ts`): at the limit it records the report file's byte length, sends SIGTERM and sends SIGKILL after a 10 s grace. Playwright's default `handleSIGTERM` closes the browsers but never exits, so `launchBrowser` passes `handleSIGTERM: false` and the gate dies with the signal. `readReport(file, { upTo })` drops every line past that offset, so a gate that kept running cannot file `check-crashed` for the pages it never reached. The row says "stopped at the Nm deadline" and `outOfTime` files that alone. A runner test that spawns a child uses a fake clock or an `AbortSignal` and kills the child in `afterEach`.
- A retry starts only when the time left exceeds the first attempt's duration (`retryFits`). A retry the deadline cuts short does not replace the first attempt: `afterRetry` keeps attempt 1's status and findings and adds the out-of-time note.
- `shardOf(list, shard, costs, offset = 0)` deals round-robin from `(index + offset) % n`. `gates.mjs` passes the gate's index in `registry.mjs` as the offset, so one-page gates land on different legs and not all on shard 1. Costed dealing (`readout-still`) ignores the offset.
- Selection: a changed file selects the pages whose import closure holds it (`.mdx`, `.astro`, `.ts`, `.tsx`, `.mjs`, `.css`; relative paths and `~/`). A change under `packages/gmt/src/<ns>/<module>/` selects the pages that import `@northguild/gmt/<ns>/<module>` plus the sample. Chrome files (`src/styles/*`, Starlight overrides, `astro.config.mjs`, `apps/dox/package.json`, `pnpm-lock.yaml`), any other library change and any `apps/dox/` file no page closure holds select the sample (`SAMPLE` in the registry; `registry.test.ts` asserts each path is in `dist`). A changed gate script runs that gate on the sample; a changed runner file (`scripts/gates/`, `gates.mjs`, `gate-checks.mjs`, `scripts/lib/`) runs every gate on the sample. A deck route (`src/pages/slides/[slug]/`) is a page at each deck's path (`gates.mjs` passes `allDeckRoutes` to `buildPages`), so a deck change selects its deck. Over 12 pages the run keeps the sample plus 6 picked evenly, plus one selected page for any gate those would leave with none (a deck for `slides-check`); `--all` lifts the cap. Test files and `apps/dox/src/test/` helpers never select a page. With no changed file under `apps/dox/`, `packages/gmt/src/` or `pnpm-lock.yaml`, the runner prints `gates: PASS  nothing to check` and does not build.
- An empty run is not a pass: when the diff selects pages but no requested browser can run an applicable gate (`emptyRunOutcome` in `gates/select.mjs`), `gates` exits 2. `contrast-measure` is Chromium only, so `--browsers firefox` alone runs nothing for it.

## CI jobs for Dox

- `dox-site` ("Dox site build") builds `@northguild/gmt` and the site once on Node 22 with `fetch-depth: 0` and uploads the `dox-site` artifact. It runs when `determine-affected` selects `dox-dist` or `dox-tables`, and on every PR reporting `dox_changed`. The artifact is one tar of `apps/dox/dist`, every gitignored generated file (`src/generated/`, reference, changelog and industry pages under `src/content/docs/`, `public/llms*.txt`) and every tracked file the build rewrote; `dist/` alone is not enough because gate selection reads `src/content/docs/**`. The pack step passes NUL-delimited names to `tar --null -T -`. It keeps 14 days with `overwrite: true` (`download-artifact` keeps the first of two same-named artifacts, #380). A failed `dox-site` skips every job that needs it.
- `consistency` keeps only fast checks and builds nothing.
- `dox-browser` unpacks the artifact, builds `@northguild/gmt`, and runs `test:dist` (`DOX_DIST_REQUIRED=1`), the browser tests and `frame-check`, on the `dox-dist` and `dox-tables` checks.
- `dox-table-fit` runs `table-fit` in four shards ("Dox tables fit (shard 1/4)" to "4/4"), Chromium only, `fail-fast` off. The `dox-tables` check (`scripts/lib/affected.mjs`) runs on every Dox change and every `packages/gmt/src` change (`GMT_LIB`) and always opens every table page: a shared change can spill a table on a page it never touched. A shard that measures no table fails.
- `dox-gates` runs on PRs reporting `dox_changed`, after `dox-site`, as five legs, each `gates --tier pr --browsers chromium --themes dark,light --no-build --against origin/<base>`. The runner exits 2 if `dist/gmt/index.html` is missing. Gates stay serial within a leg because the clock-still gates flake when gates share a runner. The legs are `readout-still` (`--only readout-still`, job 40 min and step 35; one page takes 4m35s, with the Timetable Reader 25m37s), `contrast` (`--only contrast-measure`), `canada` (`--only canada-layout-check,data-credits-check,a11y-media,frame-check`), `esc-grow` (`--only esc-cascade,grow-measure`) and `other` (`--skip` the gates the others name, so a gate added later lands here). Non-`readout-still` legs have 20 / 15 minute job / step limits. `scripts/gates/ci-legs.test.ts` reads `ci.yml` and fails when a `pr`-tier gate runs in no leg or two. The runner prints its screen at the end and appends it to `$GITHUB_STEP_SUMMARY` (`gates/step-summary.mjs`). Each gate logs to `.gates/`; a leg's step stops 5 minutes before its job so a failed leg uploads `apps/dox/.gates/` (without `vite-cache/`) as `dox-gates-<leg>-<run id>`.
- The `dox-gates` jobs are advisory until the owner makes them required. A PR touching nothing under `apps/dox/` or `pnpm-lock.yaml` skips them; a lockfile change alone runs them (Playwright or axe-core may bump).
- One Dox PR runs up to 11 Dox jobs against the organisation's 20 concurrent jobs.
