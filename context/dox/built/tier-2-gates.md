# Tier 2: gates and CI

Part of [built/index.md](index.md). Operator steps (run, baseline, weekly sweep, Firefox): [tier-6-runbooks.md](tier-6-runbooks.md).

## Gates

- Both measuring gates are diagnostics: a few px of browser difference is read, not chased. A run that measured nothing, skipped an interaction or crashed fails.
- `scripts/grow-measure.mjs` (`pnpm run grow:measure`) samples every tool page's height each frame, on load and on input, in Chromium and WebKit at 1440 and 390 px. It asserts an HTTP 200, a matching root, a largest painted jump of 48 px for the root and for `<main>`, every `.gmt-grow` at rest, a final height equal to the reduced-motion run's, and that each requested interaction happened. `rawMaxJump` is reported, never asserted. A tool's `drag` entry names the handle or range; for a custom handle the script reads its parent as the track.
- `scripts/readout-still.mjs` (`pnpm run readout:still`, no arguments) drags every handle by keyboard and pointer in Chromium and WebKit at 1440 and 390 px, plus the widget root forced to 360 and 300 px. It fails if a hero plate, the chart frame, the dragged control or anything above it moves or resizes, a required control is missing, a handle's value does not change, or it checked nothing. `handle-early`, `handle-compare` and the Timetable Reader's `handle-2` to `handle-4` are optional. Only the insides of the day track, the plot and a hold cell's live wrapper may move (`drawn`). An `entries` item takes `values` (strings, or `"options"` for a select) or `chips: true` (a `group` role named by its legend). Pass/fail logic is in `scripts/gate-checks.mjs`, tested by `gate-checks.test.ts`.
- A tool with no drag handle is in `readout-still` too when it has typed entries: `entries` carry the typed values and `controls` is empty (the PTP Clock Converter). A tool with neither (the decoders, readers, ledgers and checkers that only pick presets) is not. Its definition of done: across every preset each plate keeps its size and a held region keeps its height. A result region may grow between presets through `.gmt-grow`, which `grow:measure` gates.
- A row's `clock` makes `readout-still` hold a live clock still. A switch spec, `{ role: "switch", name, startsOn }`, is the clock itself: the PTP Clock Converter's "Live clock" (`startsOn: true`, so the base is taken while it ticks) and the Cutoff Countdown's (`startsOn: false`, because the page opens pinned, so the gate turns it on first and diffs that flip). `{ radios: [on, off], pause }` is the Expiry Calculator: its "Now" and "A date" radios start the clock and its "Live clock" switch pauses it. Every clock logs "flip and 3 ticks": three ticks are diffed against the ticking boxes (`waitForTimeout(1050)`, real time, the gate has no clock seam), then the switch is paused and turned on again, each diffed. All three clocks are held this way. The PTP page's own holds test, `ptp-clock-converter-holds.browser.test.ts`, drives a paused Playwright clock (`install`, `pauseAt`, then `runFor`) and its `now-plates` gate; the page carries the `live` hook, so `visual-snapshot` masks its plates and calls. The other two pages open pinned or in date mode, so they draw no clock text and need no mask.
- The MAR-16 tools measure the whole widget (`scope: "widget"`, frame `.gmt-gnss-frame`). Only `GNSS_DRAWN` (lanes, bars, strip, plot, rulers, a hold's live wrapper) may move; the range chip is a `riders` element. `textBoxes` excuses code-span width and unbreakable instant pieces, never a frame or plate.
- Trap: Firefox lays out in fractions, so `readout-still` compares raw boxes with a 0.5 px epsilon and never rounds before comparing. It snapshots again after the scroll into view; a box that moved with the scroll is `scroll moved <element>`. Findings group per element.
- Trap: a late writer outside `grow()` (a script setting a height after the region settled) is a jump. `attributeFrames` (`gate-checks.mjs`) splits a sample that spans two frames, and `withJumpDiagnostic` names the `<main>` frame in a `<main>`-only jump.
- `a11y-media` proves `prefers-contrast` applied before reading the border: a probe property under `@media (prefers-contrast: more)` must read `1`, mid-page and in a fresh context with `contrast: "more"`. An unset probe is `emulation-not-applied` (the engine, not the page); a set probe with a weak border token is `contrast-border-token`.
- `scripts/html-diff.mjs` compares built widget markup (a changed widget, a changed page around it, a new widget page with no baseline). `visual:diff` is the pixel gate. `html-diff.mjs` finds a widget root with or without `not-content`.
- `frame-check` (`scripts/frame-check.mjs`, tier `pr`, three engines) serves `dist` itself and checks at 1440 and 390 px: the `/install/` code frame corners, each `/upstream/` card head's icon and badge within 2 px of the title's first-line middle, and Markdown list dashes and ticks within 2 px of the first-line middle (no component list item has a dash). A page with nothing to measure fails.
- `rendered-links` (`scripts/rendered-links.mjs`, tier `pr`, Chromium, one theme) opens every built page with a `data-widget` element (`listWidgetPages` in `scripts/lib/widget-pages.mjs`, a use of the `listBuiltPages` walker in `scripts/lib/built-pages.mjs` that `listTablePages` shares, read from `dist`, never a fixed list) at 1440 x 900, waits for a widget root and `settle`, then reads the `href` attribute of every `a[href]` and `area[href]` as written. A relative value is resolved against the page with `resolveHref`, and `isPageLinkWithoutSlash` (`scripts/lib/page-links.mjs`, the predicate `test:dist` uses) judges it. Rule `page-link-without-slash` names the page, the value and the widget that holds the link; rule `check-crashed` is a page that would not load. A run that measures no page fails. Links that appear only after a click are left to each tool's own tests. Takes `--base`, `--browsers`, `--pages`, `--list-pages` and `--shard <i>/<n>`.
- `table-fit` (`scripts/table-fit.mjs`, tier `weekly`, three engines) opens every built page with a `<table` (`listTablePages` in `scripts/lib/table-pages.mjs`, read from `dist`, never a fixed count) at 1440 x 900 with every `<details>` open and every tab shown. It fails a scroll box wider than it shows; a table with no scroll box fails against its block and against `main`'s content box and by `scrollWidth` against `clientWidth`. Rule `table-scrolls`. `measureCells` (`scripts/lib/cell-overflow.mjs`, 1440 and a fresh 390 px load) fails a cell that is too small for its content or whose text reaches more than 1.5 px past it (rule `cell-overflows`); it skips visually hidden headers and `.gmt-sr-only` content. A run that measures no table fails. `--shard <i>/<n>` keeps every n-th page of the sorted list (`shardOf` in `scripts/gates/contract.mjs`, also used by the weekly sweep's legs); `--list-pages` still prints every page.
- `plate-fit` (`scripts/plate-fit.mjs`, tier `weekly`, three engines, both themes) opens every built tool page (`listToolPages` in `scripts/lib/tool-pages.mjs`, read from `dist`) once per browser, then resizes the viewport from 320 to 1920 px in `--step` 20 px steps (`--from`, `--to`; fine enough to catch a 60 px band, because the stage is not monotonic in viewport width: the sidebar, the right contents column and the full-bleed main each change it). At each width `measurePlates` (`scripts/lib/plate-overflow.mjs`) walks the text of every plate (an element in `main` whose class ends in `plate` or `Plate`) with Range rects and fails any text more than 1.5 px past the plate's padding edge. It skips `display: none`, `visibility: hidden`, `aria-hidden` and sr-only content. Rule `plate-text-overflows` is text a reader can see. Rule `plate-sample-overflows` is the hidden reserved samples (a class containing `ghost`): a sample is the widest reading the plate can show, so one past the edge means a reading would be too, even when the page now shows a short one. Rule `check-crashed` is a page that would not measure. A run that measures no plate fails. Takes `--base`, `--pages`, `--list-pages` and `--shard <i>/<n>`; `recordMeasured` counts pages times widths.
- `contrast-measure` is Chromium only. It clips a glyph rect to each scroller's client box, never its border box. Its disabled-field border check measures the visible element: for a switch, whose input is transparent, that is the track beside it (`.track`, a dashed `--gmt-ice-dim` edge at 3:1). `a11y-media`'s `forced-colors-boundary` does the same. Both match the switch's own markup (an `input[role="switch"]` at opacity 0 with an `aria-hidden` track after it); any other transparent control is judged on itself.
- `canada-layout-check` takes `--browsers` and `--engine`, checks both clock-change pages in dark and light at 1440, 1024, 420, 375 and 300 px (420 is just above the WebKit stack threshold), and measures the probe table as loaded and with the verdict forced to ok, bad and unreadable. Offsets come from the page's own config through `expectedOffsets` in `scripts/lib/clock-check-harness.mjs`.
