# Common IANA Timezones

| Region | Identifiers |
|--------|-------------|
| US | `America/New_York`, `America/Los_Angeles`, `America/Chicago`, `America/Denver` |
| Canada | `America/Toronto`, `America/Vancouver`, `America/Edmonton` |
| Europe | `Europe/London`, `Europe/Paris`, `Europe/Berlin`, `Europe/Moscow` |
| Asia | `Asia/Tokyo`, `Asia/Shanghai`, `Asia/Singapore`, `Asia/Kolkata`, `Asia/Dubai` |
| Pacific | `Pacific/Auckland`, `Pacific/Honolulu`, `Pacific/Fiji` |
| Australia | `Australia/Sydney`, `Australia/Melbourne`, `Australia/Perth` |
| UTC | `UTC` |

For the full list, call `getTimeZones()` (~422 entries, varies by runtime/ICU) or see the [IANA timezone database](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones).
