How to read the columns:

- **Test cases** is the number of tests in one run of the library's own suite.
- **CI test executions** is the test cases multiplied by every Node version and time-zone
  run the library's own CI applies.
- **Time zones**: for GMT, the zones the whole suite runs in. For the others, the zones
  their dedicated time-zone and DST test files cover. A 0 means none was found.
- **Locales**: for GMT, the locales every locale-aware function is tested in. For the
  others, the locale test files their repository holds.
- **Known failing tests** counts tests that fail on the library's own default branch.
  "Not measured" means the figure was not taken. Failures caused by the measuring machine
  are not counted here; see the notes below.

## How these were measured

Each figure for the other libraries is a snapshot taken on the date in the table, between
{measurementDates.oldest} and {measurementDates.newest}. Libraries change their tests and
CI, so check the date before you cite a figure. GMT's own figures are not a snapshot:
`scripts/stats.mjs` regenerates them from this repository on every change, and the build
fails if a published figure drifts from the repository.

## How GMT's own suite is designed

GMT's suite balances thoroughness against maintenance by testing behavior, not
permutations.

**What it tests exhaustively**

- **The locale matrix.** Every locale-aware function runs in all {gmtStats.locales} locales of the
  matrix: {gmtStats.localeList.join(", ")}. The set covers script direction,
  first-day-of-week differences and calendar metadata.
- **The time-zone matrix.** Every zoned function runs in {gmtStats.timezones} IANA time zones that span every UTC
  offset band, from {zoneOffsets.min.zoneId} ({formatOffset(zoneOffsets.min.minutes)}) to {zoneOffsets.max.zoneId} ({formatOffset(zoneOffsets.max.minutes)}).
  The set includes zones with DST transitions and zones at half-hour offsets.
- **Zero-length and identity cases.** Every interval and arithmetic function is tested with
  zero-length inputs, identity operations and values next to a boundary.
- **Invalid-input sentinels.** Every public function is tested for its documented fallback
  (`""`, `null`, `false` or `[]`) on malformed strings, wrong types, leap seconds and
  inverted intervals.

**What it collapses**

- **Non-string input tables.** A function that guards with `typeof x !== "string"` returns
  the same sentinel for `null`, `undefined`, `123`, `true`, `[]` and `{}`. The suite tests
  one representative non-string per argument position, not every type at every position.
  That is safe because every non-string type reaches the same early return.
- **Repeated permutations.** Adjacent, disjoint and reversed interval cases that give
  identical results are not repeated for every function variant. The `plain`, `zoned`,
  `utc` and `unix` families share the same mathematical behavior, so each family gets the
  fewest cases that prove it.

**The result.** {formatCount(gmtStats.tests)} tests in {formatCount(gmtStats.files)} files. CI runs them as
{formatCount(gmtStats.executions)} executions: every test, in {gmtStats.nodes.length} Node versions and {gmtStats.timezones} time zones,
which is {runsPerTest} runs of each test.
