Current release: **v{gmtVersion}**

`@northguild/gmt` wraps `@js-temporal/polyfill` behind a smaller, more opinionated API
aimed at the cases application code actually hits: arithmetic, comparison, parsing,
formatting, unix conversions, timezone conversion, and validation.

## Key features

<CardGrid stagger>
  <Card title="100% Temporal, Temporal-first" icon="star">
    Built directly on the TC39 `Temporal` standard, not a homegrown date/time type system.
    No `Date` object anywhere, enforced by three dedicated lint packages.
  </Card>

<Card title="A complete date/time solution" icon="approve-check">
  Combines all essential date/time capabilities into one library, with features

</Card>

<Card title="~15× more CI test executions" icon="rocket">

</Card>

<Card title="Explicit DST disambiguation" icon="setting">
