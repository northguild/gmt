Current release: **v{gmtVersion}**

`@northguild/gmt` wraps `@js-temporal/polyfill` behind a smaller, more opinionated API
aimed at the cases application code actually hits: arithmetic, comparison, parsing,
formatting, unix conversions, timezone conversion, and validation. No hardcoded offset
tables, no `Date` object — every zone on the globe above is computed live in your
browser and recomputed every second.
