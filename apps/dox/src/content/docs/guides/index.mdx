These guides are organized by task, not by namespace. Each one gathers the runnable
patterns for a task into a single page, then links to the reference page of every function
mentioned for its full signature. The [agent skills](/guides/integration/skills/) teach the
same patterns to coding agents.

## How the guides are organized

| Group                                             | What it covers                                                                                                 |
| ------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| [Concepts](./concepts/)                           | Plain vs zoned, DST disambiguation                                                                             |
| [Core Date Operations](./core-date-operations/)   | Getting the current time, arithmetic, comparison, durations, parsing, formatting, validation, calendar systems, business calendars, operating hours, nanosecond precision, spans |
| [Zoned Date Operations](./zoned-date-operations/zoned-operations/) | Timezone-aware arithmetic, boundaries, DST control, [zone-aware buckets](./zoned-date-operations/calendar-boundaries/), [offset-preserving instants](./zoned-date-operations/offset-instants-and-local-resolution/) |
| [Conversion](./conversion/)                       | Between plain/zoned/unix/UTC and calendar systems, and foreign epochs (NTP, FILETIME, Excel, PostgreSQL) |
| [Intervals](./intervals/interval-basics/)                         | Range math — containment, overlap, set operations, splitting                                                   |
| [Integration](./integration/)                     | Cache keys, routers, tables, lint config                                                                       |
| [Industries](./industries/)                       | The industry layers on top of the core — transport legs and dwell, cut-offs, multi-leg scheduling, punctuality and timestamp classes, free time and demurrage, billing deadlines, bill of lading dates and multimodal ETAs, EDI timestamps — with real-world scenarios |

## Reading order

If you're new to the library, read these three first — in this order:

1. [Plain vs Zoned](./concepts/plain-vs-zoned/) — the two families of types and why they never mix.
2. [DST Disambiguation](./concepts/dst-disambiguation/) — why wall-clock time breaks twice a year and how GMT controls it.
3. [Zoned Operations](./zoned-date-operations/zoned-operations/) — scheduling across timezones, the task that needs both.

After that, jump to whichever group matches the task at hand.
