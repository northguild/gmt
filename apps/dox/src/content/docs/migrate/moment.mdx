## What changes

- Moment objects are mutable: `a.add(1, "day")` changes `a` and returns it. GMT returns a new string and never changes its input.
- `month()` counts months from 0. GMT counts them from 1 to 12.
- `b.diff(a, unit)` subtracts the earlier value from the later one. `diffDate(a, b, unit)` takes the earlier value first.
- Invalid input gives an object whose `format()` returns `"Invalid date"`. GMT returns `""`, `null`, `false` or `[]`.
- Time zones come from the companion package `moment-timezone`.

```js
import { diffDate } from "@northguild/gmt/plain/calculate";

diffDate("2024-03-01", "2024-03-15", "days"); // 14
```
