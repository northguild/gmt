## What changes

- Luxon values are immutable `DateTime` objects. GMT takes and returns strings.
- Luxon counts months from 1 to 12, as GMT does.
- `b.diff(a)` subtracts the earlier value from the later one. `diffDate(a, b, unit)` takes the earlier value first.
- Invalid input gives a `DateTime` with `isValid` set to `false`, and `toISO()` returns `null`. GMT returns `""`, `null`, `false` or `[]`.
- Luxon intervals are half-open. GMT includes both ends in `isBetweenDate` unless you pass `inclusiveEnd: false`.

```js
import { diffDate } from "@northguild/gmt/plain/calculate";

diffDate("2024-03-01", "2024-03-15", "days"); // 14
```

## Basic-format dates

`DateTime.fromISO` reads `20240212`, as Temporal does. GMT's validators and parsers accept only the extended format, `2024-02-12`, which is the format of RFC 3339 §5.6, so `isValidDate("20240212")` returns `false`. This is deliberate. Convert a basic-format string before you pass it on. The behaviour matrix shows the library's result in case [M9c](/compare/behaviour/#m9c-luxon).
