## What changes

- The library has immutable `CalendarDate`, `CalendarDateTime` and `ZonedDateTime` classes. GMT takes and returns strings.
- Months run from 1 to 12 in both.
- Its `Disambiguation` type has the same four values as Temporal and as GMT: `compatible`, `earlier`, `later` and `reject`.
- Invalid input throws. GMT returns `""`, `null`, `false` or `[]`.
- The library has no ISO-week call and no month difference between two dates.

```js
import { diffDate } from "@northguild/gmt/plain/calculate";

diffDate("2024-03-01", "2024-03-15", "days"); // 14
```
