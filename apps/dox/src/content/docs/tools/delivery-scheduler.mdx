<Fragment slot="keypoint">

Every handoff is an exact instant, never a wall-clock guess. One leg's arrival, plus its dwell, becomes the next leg's departure.

</Fragment>

<Fragment slot="intro">

Each leg is a departure, a duration and the zone it lands in. The summary
card leads with the ETA in the last leg's own zone, the door-to-door span, and
flags for what happened along the way: a DST change, a Date Line crossing, an
offset-table disagreement. A missed connection turns the same card into a
failure state naming the leg.

A toggle switches between two charts of the same journey. **Route** draws one
segment per leg, never sized by how long the leg took. **To scale** draws the
same legs on a real time axis. Where a fixed offset would misread a handoff,
both flag it against the offset table's naive reading — the only value the
widget computes itself, and always labelled as naive. Everything else is the
real [`scheduleDelivery`](/reference/transport/calculate/scheduleDelivery/) call for what is on screen.

</Fragment>
