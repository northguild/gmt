import CutoffStack from "../../../components/CutoffStack.astro";

The stack counts back from one event — a sailing, a flight, a loading — and
every deadline in it moves when that event moves. `cutoffSchedule` computes
each named cut-off with `cutoffAt` against the one anchor and returns the
stack sorted earliest first, so a rescheduled departure is one call and every
deadline follows it.

A closed day moves a cut-off only by the roll convention you give it: a
weekend or holiday calendar with no roll, or a roll with no calendar, has no
default, and `cutoffSchedule` returns `[]` rather than guess which way to
move it.

Reference: [`cutoffSchedule`](/reference/transport/calculate/cutoffSchedule/)
computes the whole stack; each entry is [`cutoffAt`](/reference/transport/calculate/cutoffAt/),
and a roll moves a closed day the way [`rollDate`](/reference/calendar/business/rollDate/)
moves it. See the [Cut-off Ruler](/tools/cutoff-ruler/) for one cut-off read
three ways, and the guide's
[whole-stack section](/guides/industries/transport-legs-and-dwell/#the-whole-stack-cutoffschedule)
and
[closures section](/guides/industries/transport-legs-and-dwell/#closures-roll-the-way-you-say).
