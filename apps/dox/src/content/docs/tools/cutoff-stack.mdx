<Fragment slot="intro">

The stack counts back from one event — a sailing, a flight, a loading.
`cutoffSchedule` computes each named cut-off with `cutoffAt` against that one
anchor and returns the stack sorted earliest first.

A roll moves a cut-off that lands on a closed day to an open day, earlier or
later, as you choose. Nothing moves without one. A weekend or holiday calendar
with no roll, or a roll with no calendar, has no default, and `cutoffSchedule`
returns `[]` rather than guess which way to move it.

</Fragment>
