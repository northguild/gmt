<Fragment slot="keypoint">

Two intervals that touch — one ends the instant the other starts — share no instant. The half-open functions this widget calls treat them that way.

</Fragment>

<Fragment slot="intro">

Two ranges of time can be overlapping, disjoint, one containing the other,
identical, or touching. The four interval operations answer different questions
about that relationship, and the answers are easier to see than to read.

Drag either interval's endpoints, or type them, and every operation recomputes on
the same timeline scale.

</Fragment>

<IntervalVisualizer fullbleed />

<Fragment slot="after">

**Worth trying:** switch the preset to **Disjoint**. The intersection returns an
empty result, which is the correct answer and not an error — this widget renders
that case differently from invalid input on purpose, because the library returns
the same sentinel for both.
