## What you get

Every public function, type and regex is a flat named export of the package root, and
`Temporal`, `Intl` and `toTemporalInstant` are re-exported from `@js-temporal/polyfill` beside
them. There are no namespace objects to import — a namespace is a subpath:

```typescript
// Everything is available from the package root
import { addDate, formatRelativeZoned, getNow, Temporal } from "@northguild/gmt";

// A namespace subpath, if you only want one family of helpers
import { addZoned, getZonedNow } from "@northguild/gmt/zoned";
import { addUtc, getUtcNow } from "@northguild/gmt/utc";
import { addUnix, getUnixNow } from "@northguild/gmt/unix";

// A module subpath narrows further, to one namespace's module
import { addDateTime, diffDate } from "@northguild/gmt/plain/calculate";

// Types come from the `types` subpath
import type { BusinessCalendar } from "@northguild/gmt/types";
```

Every namespace subpath except `types` also re-exports `Temporal`, `Intl` and
`toTemporalInstant`, so `import { Temporal, addZoned } from "@northguild/gmt/zoned"` needs no
second import.

Module subpaths (`@northguild/gmt/<namespace>/<module>`) exist for every namespace except
`regex` and `types`, which you import whole. The reference lists each export under its
namespace and module.

## AI Agent Skills

Every `@northguild/*` package ships [TanStack Intent](https://intent.tanstack.com)
skill files inside the npm tarball — versioned, task-routed guidance that you can
hand to a coding agent so it works with the right GMT API for each job. A skill
carries the core rules and the common pitfalls, and points the agent to this site
(`https://gmt-dox.northguild.workers.dev/llms.txt`, plus the `.md` twin of any page) and
to the JSDoc in the installed package for signatures and examples.

Discover and load them with the Intent CLI:

```bash
# 1. One-time setup — writes skill-loading guidance into AGENTS.md
npx @tanstack/intent@latest install

# 2. Discover all available skills from installed packages
npx @tanstack/intent@latest list

# 3. Load a specific skill into an agent session
npx @tanstack/intent@latest load @northguild/gmt#gmt-basics
```

The linter packages (`@northguild/gmt-eslint`, `@northguild/gmt-oxlint`,
`@northguild/gmt-biome`) use the same mechanism. Intent auto-detects your package
manager and generates the correct runner (`npx` / `pnpm dlx` / `yarn dlx` / `bunx`).

To restrict which skills an agent may load, add an `intent.skills` allowlist to
your `package.json`:

```json
{
  "intent": {
    "skills": ["@northguild/gmt#gmt-basics", "@northguild/gmt#gmt-timezone"]
  }
}
```
